应用上次没能正常启动

这通常是因为手机系统缺少「Android System WebView」组件，或者系统限制了它。请按下面的办法试一次；如果还不行，点下面的按钮复制这段信息发给我。

1. 到应用商店搜索并更新「Android System WebView」和「Chrome」
2. 设置 → 应用管理 → 显示系统程序 → Android System WebView → 启用
3. 设置 → 应用管理 → 作业哨兵 → 清除数据后重新打开
4. 重启手机后再试一次
